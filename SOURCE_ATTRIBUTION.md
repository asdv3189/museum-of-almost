# Source attribution

The Museum of Almost is an original fictional exhibition authored with Codex assistance. Exhibit names, dates, prototype anecdotes, and outcomes are fiction. The six object studies are original CSS geometry; the app uses no stock images or externally generated images.

The implementation uses Next.js, React, Sanity, the official Sanity JavaScript client, and the development/test packages listed in package.json and pnpm-lock.yaml. Their upstream licenses remain applicable; this archive does not relicense third-party dependencies. No bundled node_modules or external assets are included.

Official sources are linked in README.md. BUILD_LOG.md records the actual implementation process, observed failures, fixes, and remaining limits. A public source archive is not proof of a deployed app, live integration, judge access, or contest submission.
